# 🏨 Hotel Management System

A modern **Full-Stack Hotel Management System** designed to simplify and manage hotel operations including rooms, bookings, employees, housekeeping, accounting, and branch management.

## 🚀 Live Demo

🔗 **[View Live Project](https://hotel-management-system-tejaswi14.vercel.app/login)**

---

## ✨ Features

- 🔐 Secure Authentication & Login
- 👥 Role-Based Access Control
- 🏨 Hotel & Branch Management
- 🛏️ Room Management
- 📅 Booking Management
- 👨‍💼 Employee Management
- 🧹 Housekeeping Management
- 🍽️ Kitchen Management
- 💰 Accounting & Salary Management
- 📊 Dashboard & Reports
- 🌐 Multi-Branch Support
- 👤 User & Profile Management
- 🎨 Modern & Responsive UI
- ✨ Smooth Animations & Transitions
- ⚡ Fast and Interactive User Experience

---

## 👨‍💼 User Roles

### 🔴 Super Admin

- Manage hotels and branches
- Manage administrators and users
- Monitor overall system operations
- Manage system-level settings

### 🔵 Admin

- Manage rooms and bookings
- Manage employees
- Manage branch operations
- Access accounting and reports

### 🟢 Employee

- Access assigned modules
- Manage daily hotel operations
- Perform department-specific tasks
